[CODES & SUBSYSTEMS] Firmware Architecture & On-Target Test Suites

ECU codebase breakdown, verified silicon assertions, and hardware pin mappings

ESP-IDF v5.1+ • Target: ESP32-S3
PEDALS_FW 7 Unit Tests

Pedals & Safety Interlock ECU

Reads dual throttle potentiometers (ADC1_CH3 / ADC1_CH4), computes travel percentages, applies 5% deadzone clamping, and enforces brake implausibility interlocks (brakes > 10% clamps throttle to 0%). Broadcasts calibrated pedal data over CAN at 100 Hz.

Source: main/ & main/test_main.c
CAN ID: 0x011 (PEDAL_THROTTLE_OUTPUT)
Hardware Pinout: GPIO 17 (TX), GPIO 18 (RX)
LIGHTS_FW 3 Unit Tests

Exterior Lighting & Hazard ECU

Controls left/right turn signal flashers, emergency hazards, regenerative brake illumination, and headlight relays. Validates analog voltage conversions and monitors incoming brake interlock packets across the differential bus.

Source: lights_fw/ & lights_fw/test_main.c
CAN ID: 0x021 (LIGHT_COMMAND)
Hardware Pinout: GPIO 17 (TX), GPIO 18 (RX)
CAN_DRIVER Core HAL

Hardware CAN Controller HAL

Low-level wrapper over the ESP32-S3 Two-Wire Automotive Interface (TWAI). Manages FreeRTOS queue ring buffers (RX/TX), hardware interrupt handlers, bus-off auto-recovery, and uninitialized safety guarantees.

Implementation: components/can_driver/CAN_driver.c

[CAN SPECIFICATION] CalSol Gen 11 CAN 2.0B Message Dictionary

Bus bitrate: 500 kbps • Identifier standard: 11-bit Standard ID • Transceiver: TI TCAN332

ID (Hex) Signal Name Transmitter ECU Rate DLC Byte Layout & Signal Scaling
0x001 SYS_HEARTBEAT All Nodes 1 Hz 2 B Byte 0: Node ID (0x01=Pedals, 0x02=Lights) • Byte 1: Status Flag (0x7B=OK)
0x011 PEDAL_THROTTLE pedals_fw 100 Hz 1 B Byte 0: Throttle Percentage [0x00=0% to 0x64=100%]; Clamped to 0 on brake
0x021 LIGHT_COMMAND lights_fw 20 Hz 1 B Bit 0: Left Turn • Bit 1: Right Turn • Bit 2: Hazard • Bit 3: Brake Active

[INJECTION WORKFLOW] Automated & Manual Fault Injection Scenarios

Procedures for verifying vehicle ECU safety response under adverse CAN bus conditions

Scenario 1: Brake-Throttle Interlock

Injects brake active packet (0x021 # 08) while throttle pedal is depressed. Asserts that the pedals firmware immediately zeroes motor command output.

cansend can0 021#08
Scenario 2: Watchdog Timeout

Suspends transmitter injection for > 250 ms. Asserts that the receiver enters safe failover mode and illuminates the fault dashboard LED.

# Withhold heartbeat frames
Scenario 3: Corrupt CRC Recovery

Forces dominant bits during transmission to trigger physical bus-off state. Asserts that the TWAI controller driver executes autonomous re-initialization.

twai_initiate_recovery()
